# Preact example

Standalone Preact app. It imports no other example app and no React runtime.
Only UI components are shared through `@smolter/ui`.

```sh
pnpm install # repository root
pnpm --filter @smolter/preact dev
pnpm --filter @smolter/preact build
```

Open http://127.0.0.1:5174.

- `/`: counter, fetcher POST, automatic and manual revalidation.
- `/tasks`: loader-backed list and route-targeted create form.
- `/tasks/:id`: PATCH to rename, DELETE to remove, validation errors, no-op revalidation skip.
- `/about`: why data belongs outside components.

Client loaders/actions own the data in localStorage. This example needs no backend. Reads and mutations live beside each route, outside components.

The flat file table is generated by `fileRouter()` in `vite.config.ts`.
To use manual routes, import `{ routes }` from `./manual-routes` in `src/main.ts` and remove `fileRouter()` from `vite.config.ts`.

Version remains 0.0.1.

Use `SMOLTER_ROUTES=manual pnpm --filter @smolter/preact dev` to select the explicit route tables. File routing is the default.
