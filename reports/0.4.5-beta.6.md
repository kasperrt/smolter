# 0.4.5-beta.6 audit and measurements

## Scope

Five convention/correctness passes followed by eight optimization passes (six requested initially, then two additional size passes). All changes stay in Smolter. Public exports, dependencies and consumer configuration remain unchanged.

## Review passes

1. Enforce guarded async/await, explicit types and contiguous code with AST lint.
2. Audit package ownership and adapter parity; remove forwarding-only modules and fix Preact document rendering without an optional root module.
3. Audit cancellation, mutation protection and deferred/recovery ownership; release prefetch protection on synchronous submission failure.
4. Audit examples, guides and build tooling; preserve explicit lazy-export selection and conservative feature detection.
5. Review the complete diff and run coverage, packed consumers, production SSR, browser/HMR and docs gates.

## Optimization passes

1. Consolidate duplicate speculative-read settlement observers without changing abort or consume-once behavior.
2. Cache at most 256 parsed pattern strings. Reject static-only and object-keyed prototypes that slowed other supported workloads. Cache neither modules nor params/data; eviction does not limit route count.
3. Measure and reject a single-regex serializer: it was slower for small, large and heavily escaped payloads. Preserve existing escaping.
4. Keep import and module preparation inside one lazy-route error guard; both adapters can retry after either fails.
5. Remove redundant root-error normalization; preserve SSR, recovery and optional feature boundaries.
6. Compare full entrypoints and navigation workloads against a freshly built beta.5, including cold-pattern churn. Preserve existing size budgets.
7. Consolidate response normalization into one deferred-resolution path.
8. Replace mutually exclusive hydration settlement comparisons with one success/error branch.

The last two passes save 6–7 gzip bytes in the complete application fixtures; these are small reductions, not a claim that the whole release is smaller.

## Timing evidence

25 alternating samples per version after five warmups, 1,000 operations per sample, Node v25.9.0. Navigation uses 100 static routes and alternates first/middle/last destinations; data navigation adds trivial loaders. Fresh-object matching clones the same route table per operation. Cold churn creates 20 previously unseen dynamic patterns per operation and matches the last. Times include the operation loop and route creation where applicable.

| Workload | beta.5 median / p95 ms per 1,000 | beta.6 median / p95 ms per 1,000 |
| --- | ---: | ---: |
| navigation | 3.931 / 4.075 | 1.728 / 1.786 |
| dataNavigation | 9.325 / 11.191 | 7.081 / 8.816 |
| freshRouteObjects | 3.867 / 4.125 | 1.610 / 2.986 |
| coldPatterns | 3.227 / 4.954 | 6.413 / 8.193 |

Repeated routes benefit; genuinely cold pattern churn is slower because of cache insertion/eviction. These API microbenchmarks do not establish browser LCP, TTFB, interaction latency or general performance superiority. No matched consumer performance run was performed.

## Regression focus

- Synchronous speculative submission failure releases protection, allowing subsequent prefetch.
- Document rendering without an optional root module works in both adapters; the Preact regression failed with the previous conditional.
- Mutable/frozen routes, shared path patterns with distinct modules/params and eviction beyond 256 patterns remain correct.
- Both lazy adapters retry after module preparation throws, not only rejected imports.
- Existing recovery presentation, mutation non-replay, streaming ownership, scoped transport, CSP/CDN/head preservation and HMR assertions remain blocking.

## Consumer testing

Upgrade all applicable declarations and lockfile to `0.4.5-beta.6` from npm beta. No API or configuration migration is required. Preserve native patches; do not add package patches or aliases. Rerun production builds, existing ownership/recovery tests and genuine missing-chunk Admin redirect recovery, then measure initial transfer and actual interaction separately from emitted asset totals. Native/device parity and the full consumer network/race matrix are not signed off by this upstream audit.

## Final local validation

- Lint (Biome plus AST conventions), typechecking and generated API-reference validation passed.
- 441 tests across 64 files; runtime/tooling line coverage 100% (2,183/2,183).
- 71 browser scenarios passed with file routing, then all 71 passed with manual routing, including production streaming/recovery and development route HMR.
- Packed React 18/19 and Preact installations, SSR and TypeScript 7 browser/SSR prefetch builds passed.
- Production React/Preact SSR and hosted Preact documentation smoke checks passed.
- JSR dry-run validation and existing size budgets passed; the prefetch build budgets also passed explicitly under Node 22 and Node 24.
- One intermediate browser run overlapped source/dist rebuilds and failed Preact SSR navigation; it was stopped. Both complete final browser runs above used a stable build and passed without relaxed assertions.
- No consumer/native parity or performance superiority claim follows from these upstream checks.
